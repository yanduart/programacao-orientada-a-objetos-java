# Programação Orientada a Objetos em Java

Projetos e exercícios de Programação Orientada a Objetos desenvolvidos durante o curso de Ciência da Computação.

## Projetos

| Projeto | Tema |
|---|---|
| [Aula_Heranca](./Aula_Heranca) | Conceitos de herança em Java |
| [Exercicio_Heranca](./Exercicio_Heranca) | Exercício prático de herança |
| [Heranca_Funcionario](./Heranca_Funcionario) | Hierarquia de classes de funcionários |
| [Aula_Tratamentos_Erros](./Aula_Tratamentos_Erros) | Tratamento de exceções (try/catch/finally) |

## Tecnologias

- Java 21
- Maven
- NetBeans

## Como executar

1. Clone o repositório ou baixe o ZIP.
2. Abra o NetBeans e vá em **File → Open Project**.
3. Selecione a pasta do projeto desejado (ex.: `Aula_Heranca`).
4. Clique com o botão direito no projeto e escolha **Run**.

Requisito: JDK 21 ou superior.

(troque `Aula_Heranca` pela pasta do projeto desejado)
