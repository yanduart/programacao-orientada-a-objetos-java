# Programação Orientada a Objetos em Java

Projetos e exercícios de Programação Orientada a Objetos desenvolvidos durante o curso de Ciência da Computação.

## Projetos

| Projeto | Tema |
|---|---|
| [Aula_Heranca](Aula_Heranca) | Conceitos de herança em Java |
| [Exercício_Herança](Exercicio_Heranca) | Exercício prático de herança |
| [Heranca_Funcionario](Heranca_Funcionario) | Hierarquia de classes de funcionários |
| [Aula_Tratamentos_Erros](Aula_Tratamentos_Erros) | Tratamento de erros (try/catch/finally) |
| [Classe_Abstract](Classe_Abstract) | Classes abstratas e polimorfismo (FormaGeometrica, Retangulo e Circulo) |
| [Classe_Abstract_Situação_Problema](Classe_Abstract_Situacao_Problema) | Situação-problema com classe abstrata: cálculo de frete (Entrega Normal, Expressa e Econômica) |
| [Pratica_Interface](Pratica_Interface) | Interfaces e polimorfismo: interface `Impressao` implementada por `Relatorio` e `NotaFiscal` |
| [Pratica_Interface2](Pratica_Interface2) | Interfaces e polimorfismo: interface `Pagamento` implementada por Cartão, Pix e Boleto |

## Tecnologias

- Java 21
- Maven
- NetBeans

## Como executar

1. Clone o repositório ou baixe o ZIP.
2. Abra o NetBeans e vá em **File → Open Project**.
3. Selecione a pasta do projeto desejado (ex.: `Aula_Heranca`; troque pela pasta do projeto que quiser executar).
4. Clique com o botão direito no projeto e escolha **Run**.

> **Requisito:** JDK 21 ou superior.
